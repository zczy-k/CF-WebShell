# 使用与排错

这份文档管「装好之后怎么用」：界面长什么样、每个功能到不到位、出问题怎么对。

想自己打一个包 → [BUILD.md](BUILD.md)。想开自动同步 → [worker-sync/DEPLOY.md](../worker-sync/DEPLOY.md)。

## 一、打开 App 看到什么

| 版本 | 启动后看到 | 用户还能做什么 |
| --- | --- | --- |
| **通用壳** | 站点列表（空的），点"添加站点"输网址 | 想加多少站点加多少，每个站点独立保存 Cookie，等同于一个"多站点浏览器 + 全功能下载器" |
| **白标版** | 直接是那个网站（名字、图标、主题色都是它的） | 默认站点固定，但设置里**仍然可以再加别的站点**（除非构建时把 `allow_add_site` 关掉） |

两种产物是**同一份代码**，白标版只是构建时覆盖了 `assets/preset.json` 和图标，不是另开一套分支。

界面构成：

- **首页**：站点卡片列表（长按可编辑名称/地址/请求头/Basic Auth、换图标、清登录态、删除）；
- **浏览页**：网页铺满（**没有顶栏**）+ 一条底栏装下全部功能 —— 左：后退 / 回到首页 / 前进，
  右：下载 / 刷新 / 更多；加载进度是底栏上沿的 2dp 细线，不吃额外高度。
  页标题、地址、站点设置这些低频信息收进「更多」里。**壳不在网页上叠任何浮层**，
  所以永远不会挡住网站自己的按钮（悬浮胶囊就因为压住笔记站的「刷新 / 退出」被撤掉了）；
- **下载页**：进度、暂停/继续/取消/重试、打开文件、另存为、在文件夹中显示、路径可复制；
- **设置页**：同时下载数、下载位置、省流（不加载图片）、清空 Cookie、清空下载记录，
  以及**自动同步**那一块（见下）。

### 自动同步（可选）

一台设备加的站点，另一台自动就有；一台删的，另一台也跟着删（删除要二次确认）。
偏好设置、图标也一起同步。

它需要一个中转站，架在**你自己的** Cloudflare 账号上，不经过任何第三方服务器、不花钱：

- 全程在浏览器里点，9 步，约 10 分钟 → [**DEPLOY.md**](../worker-sync/DEPLOY.md)
- 国内注意：`*.workers.dev` 不可用，要挂自己的域名 —— 同文档第 7 步下面那节

## 二、功能清单（对"残废壳"的逐条对照）

| 能力 | 状态 |
| --- | --- |
| 网页里能做的操作（翻页、表单、SPA、POST 跳转） | ✅ 导航不拦，只把非 http(s) 协议交给系统 |
| `target="_blank"` / `window.open` | ✅ 在同一个视图里打开（不是"点了没反应"） |
| 普通文件下载（带 Cookie / UA / Referer / 自定义头） | ✅ 自己的下载器，断点续传、暂停/继续/取消/重试 |
| 前端生成的文件（`blob:` / `data:`）下载 | ✅ 注入脚本分片 + 消息桥落盘 |
| 长按链接下载 / 复制 / 交给系统浏览器 | ✅ |
| 上传（`<input type=file>`、多选、相机、Windows 拖拽） | ✅ 引擎原生选择器 |
| 下载落点 | ✅ Android 到 `Android/media/<包名>/Download`（免存储权限，**文件管理器看得见**；老版本的 `Android/data/…` 会自动迁移过来），"另存为"走系统选择器；Windows 默认用户目录下的「下载」，可改任意目录 |
| 下载能否进 App 的下载列表 | ✅ Android 靠引擎的下载事件 + `a[download]`/blob；Windows 引擎不给事件，靠"注入脚本 + 导航接管"认 `a[download]`、blob、扩展名像文件（zip/pdf/apk/docx…）、`?download` 查询串、以及链接文字写着"下载/保存/导出"（POST 表单类下载除外，见 [ARCHITECTURE](../ARCHITECTURE.md) §11）|
| 打开下载好的文件 / 在文件夹中显示 | ✅ Android 交给系统关联应用；Windows 用资源管理器 |
| 登录状态保持 | ✅ Cookie 存在 App 自己的 profile 里，重启仍在 |
| 每个站点单独的登录态清理 | ✅ 按域名清 Cookie，不影响别的站点 |
| 自定义 UA / 自定义请求头 / Basic Auth | ✅ 密码不进配置文件：Windows 走 DPAPI 加密（`secrets.bin`），Android 靠 App 私有目录 + 构建期关掉 `allowBackup`（强度差异见 [ARCHITECTURE](../ARCHITECTURE.md) §6.1） |
| 网页权限（摄像头/麦克风/定位） | ✅ 弹框询问；非 https 直接拒 |
| 站点图标 | ✅ 自动抓 favicon / apple-touch-icon，抓不到用首字母 |
| 省流模式（不加载图片）、同时下载数 | ✅ 设置页可调 |
| 多设备自动同步 | ✅ 可选，需自建 Cloudflare Worker，见 [DEPLOY.md](../worker-sync/DEPLOY.md) |
| 流媒体（`m3u8` / 分片）下载 | ❌ 不承诺，请用专门的下载工具 |
| 系统通知栏下载进度 | ❌ 未做（进度在 App 内下载列表 + 角标） |
| 每站点 profile 严格隔离（多进程/独立数据目录） | ❌ 未做：目前共用一份 profile，按域名清 Cookie；见 [ARCHITECTURE](../ARCHITECTURE.md) §6 |
| Windows 的下载拦截 / 上传对话框 / Basic Auth / 全屏事件 | ⚠️ 引擎不提供（见 [ARCHITECTURE](../ARCHITECTURE.md) §7）：下载与全屏有注入脚本兜底，上传走 WebView2 内建选择器，Basic Auth 等第二步自写 WebView2 宿主 |
| iOS / macOS / Linux | ❌ 不在范围 |

## 三、用的时候出问题

| 症状 | 原因 | 怎么办 |
| --- | --- | --- |
| 装完还是旧图标 | 系统桌面图标缓存 | 卸载重装；安卓换图标必须重装 |
| Windows 端窗口打不开 / 白屏 | 缺 WebView2 运行时 | 装 [Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；或确认系统 Edge 是新的 |
| 下载全部 403 / 下到的是登录页 | 少带了 Cookie / UA / Referer | 确认站点是先从 App 内登录的（不是系统浏览器）；必要时在该站点设置里配 UA 或请求头 |
| **下载完了，文件在哪？** | —— | 「下载」页每条记录下面就是落点目录，页面底部也有，右边两个按钮：「打开文件夹」（Windows，直接开目录）和「复制路径」；设置页同样有。Android 上系统没有"打开文件夹"，用每条记录里的「另存为」把文件放进你想放的地方 |
| Android 上看不到下载的文件 | 落点是应用私有目录 | 已经是 `Android/media/<包名>/Download`（文件管理器翻得到，一般就在 手机存储 → Android → media → \<包名\> → Download）。如果还是找不到：用记录里的「另存为」存到「下载」目录，或用记录里的「打开文件」交给能打开它的应用 |
| Windows 上点下载，下载列表里什么都没出现 | WebView2 的下载事件上游没接到原生（[ARCHITECTURE](../ARCHITECTURE.md) §7），脚本只能认出"像下载"的链接 | ① 先去「下载」页点「打开文件夹」看系统的「下载」目录 —— 兜底没覆盖的下载会由 WebView2 自己落在那里；② 用长按链接 →「下载这个链接」强制走 App 下载器；③ 还不行请把那个页面的网址发我，我给脚本再加一条触发规则 |
| 某个按钮点了没反应 | 站点用了 `window.open`、`blob:` 或特殊协议 | 已在引擎回调里覆盖；仍有问题请附网址反馈 |
| 输入框点一下就丢失焦点 / 要连点两次才能输入 | WebView 焦点没跟着触摸走 | 已修（`9761ffa`）。还遇到请附机型与系统版本 |
| 同步一直"连不上" | 服务地址填错，或 `workers.dev` 在国内不可用 | 地址末尾不要带 `/`；国内换自定义域名，见 [DEPLOY.md](../worker-sync/DEPLOY.md) 第 7 步 |
| 同步后站点没变 | 还在轮询周期内（最多几十秒到几分钟） | 点一下「立即同步」 |
| 设置页弹出「检测到一次大量删除」黄条 | 有护栏：一次要少掉一半以上站点时会停下来等你确认 | 是你自己删的点「确认删除 N 个」；不是你干的点「恢复上一版」 |
